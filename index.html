Scanner réseau local

Terminé

Un script Python qui découvre tous les appareils connectés à mon réseau domestique — sans aucun outil ni matériel à acheter, juste mon PC.

Le problème

Savoir précisément quels appareils sont connectés à ma box, et comprendre comment un réseau local s'organise réellement.

La démarche

Détection du sous-réseau, balayage ping en parallèle (threads) sur les 254 adresses possibles, puis lecture de la table ARP pour les adresses MAC.

Le résultat

Le script tourne du premier coup et retourne une table lisible, avec repérage automatique de mon propre PC.

$ python scanner_reseau.py

Ton adresse IP     : 192.168.1.154
Sous-réseau scanné : 192.168.1.0/24
Scan en cours (ça prend 10-20 secondes)...

4 appareil(s) trouvé(s) :

ADRESSE IP        ADRESSE MAC
--------------------------------------
192.168.1.14      xx-xx-xx-xx-xx-xx
192.168.1.149     xx-xx-xx-xx-xx-xx
192.168.1.154     inconnue              <- ton PC
192.168.1.254     xx-xx-xx-xx-xx-xx
APPAREILS DÉTECTÉS4
TENTATIVES AVANT SUCCÈS1
DÉPENDANCES EXTERNES0
Ce que j'ai appris — comment fonctionne une table ARP, pourquoi paralléliser les pings change tout niveau vitesse, et comment lire l'architecture de mon propre réseau domestique.

Station météo connectée

Terminé

Une station physique (microcontrôleur MicroPython) qui lit un capteur de température/humidité, affiche les valeurs sur un écran LCD et un bandeau LED, et sert une page web en direct sur le réseau du lycée — sans aucun framework.

Le problème

Afficher la météo ambiante sur un objet physique, mais aussi pouvoir la consulter à distance depuis n'importe quel navigateur du réseau.

La démarche

Lecture d'un capteur DHT11, driver bas niveau pour un écran LCD 128×64 en SPI, LED qui change de couleur selon la température, mini serveur web en socket brut.

Le résultat

Affichage en direct sur l'écran, LED qui passe du bleu au rouge selon le seuil, page web qui se rafraîchit automatiquement toutes les 10 secondes.

CAPTEURDHT11
ÉCRANLCD SPI 128×64
RAFRAÎCHISSEMENT10 s
Ce que j'ai appris — écrire un driver bas niveau pour un écran (protocole SPI, envoi d'octets bruts), monter un serveur web minimal sans framework avec de simples sockets, et générer du HTML dynamiquement depuis Python embarqué.
